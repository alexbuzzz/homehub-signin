# Home Hub — sign-in page

A tiny static page for Home Hub, a private family planner. It passes the phone on to Google's own sign-in and then
shows the one-time code as a QR for the wall tablet's camera. No secrets, no analytics, nothing kept or sent anywhere.

- `index.html` — the page (also the app's home page).
- `privacy.html` — what Home Hub uses from Google and how to remove access.
- `qrcode.js` — QR Code Generator for JavaScript, © Kazuhiko Arase, MIT.

The source lives in the Home Hub project (`signin/`); this repo only publishes it on GitHub Pages.
